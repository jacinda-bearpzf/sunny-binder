# sunny-binder

PostgreSQL · Edge Computing · gRPC

给自己省点事的小工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/sunny-binder.git
cd sunny-binder
chmod +x run.sh
```
